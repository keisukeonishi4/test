# 野菜遺産 公式サイト プロトタイプ

関係者に見せて操作感を確認するためのプロトタイプです。決済・ログインはモックで、名前・価格・人数などはすべてダミーです。

- 公開URL：https://test-blush-alpha-10.vercel.app
- ワイヤーフレーム：`docs/wireframes/`
- 開発ルール：`CLAUDE.md`

## ローカルで動かす

```bash
npm install
npm run dev
```

http://localhost:3000 を開きます。

## 確認コマンド

```bash
npm run typecheck
npm run check:words
npm run build
```
